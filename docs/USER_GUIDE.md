# User guide

**EN** / [中文](USER_GUIDE.zh-CN.md) · [Home](../README.md)

## 1. Add your video

Create a project, upload a video, then upload SRT/VTT subtitles or detect captions. Review the text and timing before continuing.

## 2. Choose a voice

Choose a preset, or upload a clear 3–30 second reference recording with its exact transcript. Click **Audition voice**. Use spoken-text overrides to fix pronunciation without changing the captions.

## 3. Preview and sync

Select a subtitle and pause where it should start. Click **Align selected cue to this frame**. Positive offsets delay the voice; negative offsets move it earlier. Generate a 3–90 second preview and check the beginning and end.

## 4. Export

Click **Approve this preview**, then **Render final video**. Download the MP4, WAV and SRT. If you change settings, generate and approve a new preview first.

The new voice replaces the whole original soundtrack, including music. Your original file is preserved.

Need help? See [setup and troubleshooting](SETUP.md).
