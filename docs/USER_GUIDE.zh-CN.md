# 使用指南

[EN](USER_GUIDE.md) / **中文** · [首页](../README.zh-CN.md)

## 1. 添加视频

新建项目，上传视频，再上传 SRT/VTT 字幕或选择字幕识别。继续前，先检查文字和时间。

## 2. 选择声音

选择预设音色，或上传 3–30 秒的清晰参考录音并填写准确文字。点击「试听音色」。需要纠正发音时，修改单句实际读法即可，不必修改字幕。

## 3. 预览与同步

选择一条字幕，将视频暂停在它应该开始的位置，点击「用当前画面校准所选字幕」。正偏移让声音延后，负偏移让声音提前。生成 3–90 秒预览，检查开头和结尾是否同步。

## 4. 导出

点击「试听满意，确认此版本」，再点击「生成最终视频」。完成后下载 MP4、WAV 和 SRT。修改设置后，需要重新生成并确认预览。

配音会替换整个原音轨，包括背景音乐；原始文件会保留。

遇到问题？查看[安装与常见问题](SETUP.zh-CN.md)。
